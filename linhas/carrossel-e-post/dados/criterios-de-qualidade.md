# Critérios de qualidade

| Critério | Aceita | Reprova |
|---|---|---|
| Formato | carrossel para ideia em partes, post para ideia de uma frase | carrossel de duas imagens no lugar de um post |
| Capa | promessa concreta, legível a 100 px | título genérico ou ilegível na miniatura |
| Corpo | 80 a 130 caracteres por imagem, até duas frases (C-22) | texto cortado ou encolhido para caber |
| Visual | toda imagem com visual ligado ao texto | caixa vazia, imagem quebrada, visual sem relação |
| Miolo | no máximo uma imagem só de texto | duas ou mais |
| Chamada | uma por peça, igual na última imagem e na legenda | duas chamadas ou chamadas diferentes |
| Post planejado | mesma ideia e frases principais do roteiro do calendário | assunto trocado ou número inventado |
| Dados da empresa | o que falta fica entre colchetes e é avisado | preço, prazo ou número inventado |
| Contraste | aprovado pela conferência automática | reprovado em qualquer imagem |
| Calendário | post planejado atualiza o mesmo cartão, na data do plano | cartão novo para um post que já estava planejado |
